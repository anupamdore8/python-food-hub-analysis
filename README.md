# python-food-hub-analysis
Python data analysis project exploring restaurant demand, customer behavior, delivery performance, and rating trends using the Food Hub dataset.
📊 Python FoodHub Data Analysis
This project analyzes FoodHub’s online food delivery dataset to understand restaurant demand, customer behavior, delivery performance, and rating trends. The goal is to help the company improve customer experience and optimize restaurant partnerships.
